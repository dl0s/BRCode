# Q10 人工验收卡

目标 192.168.1.61 / PIN 2C3353AC，当前候选版本 1.0.0.3（系统输入法）。开始前记录日期、固件、BRCode 版本及正式 BAR 哈希。未做的项目填 **NOT TESTED**。

1. **启动与相机**：点 BRCode 图标，允许相机；使用另一设备展示文本 QR，确认后置预览和结果。停留同一码十秒只增加一条记录；点击继续扫描，重复同一码应增加一条新记录。
2. **相机异常与生命周期**：拒绝权限、其他应用占用、离页、后台、锁屏、解锁、反复进入扫描页。确认有原因与重试；生成/历史页不占用相机，旧帧不弹出结果。
3. **保真与历史**：分别使用 `ASCII 123`、`中文二维码`、emoji `🙂🚀`、多行、`  两端空格  `、`'"<&>\%_` 和 URL。详情和完整复制逐字核对；保存标题/备注、搜索三种字段、删除一条、关闭重开确认其余记录保留。
4. **编辑副本与生成**：历史 → 编辑副本 → 改字 → 生成。原扫描记录正文保持，新生成记录只加一条。改变输入后旧 QR 消失；空串拒绝、仅空白不被 trim，超容量提示且不截断。页面切换恢复未提交草稿。
5. **显示与 PNG**：全屏黑码白底、方形、静区无覆盖。保存 PNG 后查看 UI 报告路径，用另一设备扫描屏幕和导出文件，逐字比对中文、emoji、空格、CR/LF。拒绝共享权限或不可写时显示失败并可重试。
6. **系统输入与实体键盘**：在正文/标题/备注/搜索直接输入，按系统设置切换语言，检查系统候选和中文提交。正文 Enter 换行；点生成/保存前仍在组字时检查最终正文不丢失。系统菜单及粘贴按钮可用；离页/后台不向隐藏字段输入，返回后可重新聚焦。界面应没有 BBIME 开关或候选栏。
7. **升级与失败**：保持已有原文/备注，通过同一应用身份更高版本升级后重查实际数据。存储写满/事务失败时保留当前结果、显示保存失败且不增加假成功记录；重试只保存一条。

原生图像编解码自测不代替第 1、2 项相机验收；同库回读不代替第 5 项跨设备兼容性；本工程 schema 迁移主机测试不代替第 7 项真实应用升级。
